# Compose system prompts from session mycology

## Context

Today a promoted spore can only become a skill. A lesson that is a standing
behavioral rule has nowhere to go except prose.

## Proposal (already logged as :kind :propose, unassembled)

Let a promoted spore target a RESOURCE LEDGER:

- standing behavioral rule -> `resources/{behaviors,guidelines,preferences}`
- procedure -> a skill under `skills/<name>/`

Classify at promotion, never at capture.

## OPEN QUESTION — do not implement past this line

What is the promotion gate for a ledger-targeted spore? Skills get human
review; an invariant deserves at least as much. Automatic invariant writes
are the one place this design can hurt.

Logged as `:learning/ledger-promotion-gate` with `:open-question true`.
