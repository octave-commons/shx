## Qualification addendum — 2026-10-03

Unique per-commit file names avoid a storage-path collision, not a conflict
between concurrent state changes. Semantic history still requires canonical
upstream Rheos/Clio ordering, provenance, duplicate and conflict checks; neither
side wins from a commit name, timestamp, title, or file order alone. Conflicting
histories must remain visible until the upstream engine or operator resolves
them. This is a proposal, not a local reconciliation algorithm.

The two archived query spellings (`eta-mu query` and `eta-mu receipts query`)
were explicitly future/unstable suggestions, not supported commands. For this
historical runbook, use `bb` to inspect receipt data; no eta-mu query alias is
claimed until its current upstream help is verified. Preserve both source
spellings as history, rather than inventing a canonical command.
